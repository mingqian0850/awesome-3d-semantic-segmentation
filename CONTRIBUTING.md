# Contributing

Thanks for considering contributing to **awesome-3d-semantic-segmentation**! 🎉

This is a curated list of papers, open-source projects, benchmarks, and datasets
for **3D semantic segmentation**. We welcome any corrections, additions, or
improvements.

## How to contribute

1. **Fork** this repository.
2. Create a new branch: `git checkout -b add-my-entry`.
3. Edit the relevant file(s):

   | File | What goes there |
   | --- | --- |
   | [`README.md`](README.md) | Overview, taxonomy, SOTA summary table, table of contents |
   | [`papers.md`](papers.md) | Research papers, organized by category and year |
   | [`datasets.md`](datasets.md) | Datasets (indoor, outdoor, aerial, synthetic) |
   | [`benchmarks.md`](benchmarks.md) | Benchmarks / leaderboards and evaluation metrics |
   | [`projects.md`](projects.md) | Open-source projects, frameworks, and toolkits |

4. Commit your changes with a clear message, push, and open a Pull Request.

## Guidelines for new entries

- **Accuracy first**: verify titles, venues, years, links, and numbers (mIoU,
  star counts, etc.) before submitting. "Fewer, but correct" beats "more, but
  wrong".
- **Keep it concise**: one line per entry unless a short note is genuinely
  useful.
- **Prefer official links**: link to the official project page / paper /
  repository (arXiv, GitHub, project website).
- **Mark uncertain numbers** with `~` (approximate) rather than inventing
  precision.
- **Keep alphabetical / chronological order** within each section where it
  applies.
- New entries should be **relevant, maintained, or historically important** —
  not just every paper ever published.

## Pull request checklist

- [ ] Links verified (no dead links).
- [ ] Venue and year correct.
- [ ] No duplicate entries.
- [ ] Markdown formatting consistent with the rest of the file.

## Code of conduct

Be respectful. This is a community-curated list — disagreements are fine,
hostility is not.
